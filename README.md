# BodyMetric Insight

BodyMetric Insight is a simple BMI Calculator Android application built using **Kotlin** and **Jetpack Compose**. The app allows users to enter their height and weight, calculate their Body Mass Index, and view their BMI category in a clean and responsive mobile interface.

---

## About the App

BMI stands for **Body Mass Index**. It is a general measurement used to estimate whether a person’s weight is within a healthy range for their height.

The formula used in this app is:

**BMI = weight(kg) / height(m)²**

The app asks users to enter height in **centimetres (cm)** and weight in **kilograms (kg)**. The height value is converted from centimetres to metres before calculating the BMI.

---

## Features

- Height input in centimetres
- Weight input in kilograms
- One-tap BMI calculation
- BMI result shown with 2 decimal places
- BMI category shown after calculation
- Input validation for empty or invalid values
- Simple and responsive Jetpack Compose UI
- Clean 3-page app structure

---

## App Pages

### Page 1: Welcome / BMI Introduction

This page introduces BodyMetric Insight and explains what BMI is in a simple way.

### Page 2: BMI Calculator

This page allows users to enter their height and weight, calculate their BMI, and view the result.

### Page 3: BMI Categories / Information

This page shows the BMI category ranges and includes a short note that BMI is only a general health guide.

---

## BMI Categories Used

| BMI Range | Category |
|----------:|----------|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25.0 - 29.9 | Overweight |
| 30.0 and above | Obese |

---

## How to Use

1. Open the app.
2. Read the short BMI introduction.
3. Go to the BMI calculator page.
4. Enter height in centimetres.
5. Enter weight in kilograms.
6. Tap **Calculate BMI**.
7. View the BMI value and category.
